# 03 · 参考片拆解：这类"人物解说片"为什么能成立

做《留守儿童》之前，先拆了一条同类型的片子（讲清代科举的抖音视频，5 分 24 秒，1080p）。
这份文档是当时的拆解结论，不包含原片素材。

## 一、它的骨架

| 段 | 作用 | 时长占比 |
|---|---|---|
| 钩子 | 一个具体动作 + 一个数字：三千八百多个考生走到考场门口，掉头走了 | 6% |
| 机制 | 为什么：制度是怎么把人筛掉的 | 22% |
| 细节 | 具象到能数出来的东西：一米宽的格子、九天六夜 | 30% |
| 落到人 | 一个具体的人、一件具体的事 | 26% |
| 收口 | 回到开头的那个数字 | 16% |

关键不在"讲了什么"，在**顺序**：先给一个反常的画面，再解释为什么，最后才给情绪。

## 二、它凭什么不土

1. **不做写实**。人物是白色剪影，没有五官、没有手指、没有布料。观众不会去挑"画得像不像"，只会看"发生了什么"。
2. **信息全压在字幕上**。字号极大、固定在左上角、关键词换色。画面负责情绪，字幕负责信息。
3. **每个镜头只有一个光源**。烛、窗、月亮。明暗关系简单到一眼就能读懂。
4. **画面里一直在动**。哪怕没有人物，也有尘土、光束、镜头推移。没有一帧是"摆拍"的。
5. **敢留白**。连着三四个镜头不写字。

## 三、可以直接借用的规则

- **4 秒上限**：超过 4 秒必须有三个变化点，否则切短
- **时长由动作决定**：空镜 1.5–2 秒；一个动作做完 2.5–3.5 秒；三个变化点 4–5 秒
- **不用纯黑**：夜是深蓝灰，只有最深的死角才接近黑
- **每帧一个亮点**：锁、红框、尾灯、睁着的眼睛
- **具体胜过形容**："47 次没接通"胜过"很孤独"

## 四、我们没照搬的部分

- 参考片的主题是制度，可以一直讲"规矩"；留守儿童不能，讲制度会变成控诉，所以《留守儿童》把重心放在**一个人一天里的细节**上。
- 参考片没有音乐也能撑住，因为信息密度高；我们的片子更依赖字幕与留白，所以把镜头切得更碎（59 镜 / 150 秒）。

## 五、一句总结

这类片子的门槛不在画技，在**取舍**：敢不敢把一个 5 分钟的故事压到 2 分半，敢不敢让一个镜头只有 1.5 秒。
