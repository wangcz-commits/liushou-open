## 镜头是怎么写的

每一镜一个纯函数：

```ts
export function boarding(ctx: CanvasRenderingContext2D, f: number, dur: number) {
  // f = 本镜内的帧号，dur = 本镜总帧数
  // 所有动画都写成 f / dur 的比例，改时长不用改代码
}
```

`scene-N.tsx` 只负责按 `timeline.json` 把当前帧分发给对应的函数，再叠一层字幕与空气粒子。

## 几条规则

1. **4 秒是上限**。超过 4 秒的镜头必须有三个以上的变化点，否则切短。
2. **时长由动作决定，不是由预算均分**。空镜 1.5–2 秒，一个动作做完 2.5–3.5 秒。
3. **不画纯黑**。夜是深蓝灰，只有最深的死角才接近黑。
4. **每一帧必须有一个亮的东西**：锁、红框、尾灯、睁着的眼睛、"留"字。
5. **不画脸**。情绪靠姿态、遮挡、速度和光。

## 重渲

`timeline.json` 里改 `durationFrames`，再改 `scene-N.tsx` 里的 `SHOTS[].dur` 与 `CUTS`，即可整体变速。
本项目所有镜头都按 `f / dur` 归一化，等比缩放不会踩到动画错位。
